# kewldan/homebrew-tap

Homebrew casks for [kewldan](https://github.com/kewldan)'s apps.

```bash
brew install --cask kewldan/tap/tether
```

| Cask | App |
|---|---|
| `tether` | [Tether](https://github.com/kewldan/tether), a desktop GUI for Android Debug Bridge |

Casks are updated automatically when a new release is published.
